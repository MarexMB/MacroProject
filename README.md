# Runity rune importer

Runity is a rune importer for game called League of Legends. App uses LCU(League Client Update) driver to connect to the client and change your runes based on enemy team comp. Every champion in the game has few traits that will help decision system to pick runes best for enemy team. App will wait for champ select to go to finalization and then it will pull information about enemy team and import you the best runes.
